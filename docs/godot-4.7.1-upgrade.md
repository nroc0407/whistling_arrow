# Godot 4.7.1 업그레이드 기록

- 기록일: 2026-07-25 (Asia/Seoul)
- 엔진: Godot `4.7.1.stable.official.a13da4feb`
- 렌더러: GL Compatibility
- 프로젝트 위치: `godot/`
- 프로젝트 기능 버전: `4.7`

## 변경 범위

활성 Godot 프로젝트를 4.7.1 기준으로 전환했습니다. `project.godot`의 기능 버전을 `4.7`로 올리고 현재 실행 안내의 엔진 버전을 갱신했습니다. 이 엔진 전환 단계 자체에서는 게임 규칙, 장면 구조, 입력 분류와 렌더링 방식을 변경하지 않았습니다. 이후 추가된 3D 확장은 별도 기록에서 다룹니다.

`docs/godot-port-v1.md`와 `godot-port-v1` 태그의 4.6.1 표기는 최초 포트 당시의 역사적 증거이므로 수정하지 않습니다. 4.6.1은 현재 프로젝트의 편집, import, 실행 또는 검증에 사용하지 않습니다.

## 4.7.1 검증 결과

| 검증 | 결과 |
| --- | --- |
| 엔진 버전 식별 | `4.7.1.stable.official.a13da4feb` |
| 헤드리스 편집기 import 및 GDScript 스캔 | 통과 |
| 합성 음정·분류 테스트 | 통과 |
| 게임 월드 상태·충돌 테스트 | 통과 |
| 메인 장면 10프레임 헤드리스 기동 | 통과 |

샌드박스 검증에서는 `APPDATA`와 `LOCALAPPDATA`를 프로젝트 내부의 무시된 `godot/test-output/` 경로로 분리했습니다. 이 환경에서 Windows 루트 인증서 저장소를 읽지 못했다는 경고가 출력됐지만 모든 명령은 종료 코드 0으로 완료됐으며, 프로젝트 import·테스트·장면 기동에는 영향을 주지 않았습니다.

Web export와 실제 마이크 장치 입력은 이번 엔진 전환 검증 범위에 포함하지 않았습니다.
