- 보존된 2D 장면: `res://scenes/main.tscn`

## 설계 원칙

3D에서도 플레이어가 화살의 방향이나 좌표를 직접 지정하지 않는 원래 기믹을 유지합니다. 플레이어는 휘파람 음정으로 `RETURN`, `FLOAT`, `ATTACK` 상태만 선택하며, 화살은 3차원 위치·속도와 관성을 계속 유지합니다.

- `RETURN`: 3D 홈 비콘을 향해 제한된 회전 속도로 귀환하고 근거리에서 감속합니다.
- `FLOAT`: 기존 속도를 감쇠하면서 작은 수직·수평 부유력을 적용합니다.
- `ATTACK`: 가장 가까운 살아 있는 3D 과녁을 선택하고 yaw·pitch를 함께 보간하여 추적합니다.

자유 조준을 추가하지 않은 이유는 음정 명령이라는 핵심 입력의 우선권을 보존하고, 3D 공간에서 필요한 조준 부담은 자동 항법이 담당하도록 하기 위해서입니다.

## 구현 범위

- 고정 원근 카메라가 바라보는 3D 아레나
- 절차적으로 생성되는 바닥 그리드, 홈 비콘, 조명과 발광 재질
- 몸체·화살촉·깃과 3D 잔상으로 구성된 지속형 화살
- 고도와 좌우·전후 경계를 포함한 완전한 `Vector3` 비행
- 홈으로 이동하는 발광 과녁 3개와 자동 재생성
- 3D 거리 기반 충돌, 점수, 격추 수, 홈 HP와 게임오버
- 공격 대상 주위의 3D 락온 링
- 기존 `PitchDetector`와 `WhistleArrowHUD` 재사용
- `Space`, `1`, `2`, `3`, `M` 디버그·마이크 조작 유지
- `Numpad 7`의 고정 과녁 직행·관통 순간 다음 과녁 자동 락온·연쇄 조준과 `Numpad 9`의 시작 원점 복귀 항법 테스트

최초 2D 구현은 삭제하거나 덮어쓰지 않고 별도 장면으로 보존했습니다.
